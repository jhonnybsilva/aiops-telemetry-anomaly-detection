Modelagem Relacional (SQLite)

O projeto estrutura o armazenamento de telemetria em 3 tabelas normalizadas com chaves estrangeiras e índices em colunas de alta cardinalidade:

CREATE TABLE servers (
  server_id TEXT PRIMARY KEY,
  role TEXT NOT NULL, region TEXT, specs TEXT
);

CREATE TABLE telemetry_logs (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  timestamp DATETIME, server_id TEXT,
  cpu_usage_pct REAL, memory_usage_pct REAL,
  network_latency_ms REAL, packet_loss_pct REAL,
  is_anomaly INT, failure_within_1h INT,
  FOREIGN KEY (server_id) REFERENCES servers(server_id)
);

Consulta Analítica Operacional

Query SQL utilizada para contrastar o impacto operacional de janelas de anomalia contra a operação nominal do datacenter:

SELECT
  CASE WHEN is_anomaly = 1 THEN 'Sob Anomalia' ELSE 'Normal' END AS Estado,
  COUNT(*) AS Total_Amostras,
  ROUND(AVG(cpu_usage_pct), 2) AS Media_CPU_Pct,
  ROUND(AVG(network_latency_ms), 2) AS Media_Latencia_ms,
  ROUND(AVG(packet_loss_pct), 3) AS Media_Perda_Pacotes
FROM telemetry_logs
GROUP BY is_anomaly;
